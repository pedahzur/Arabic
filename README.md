# הוראה משולבת של ערבית ספרותית ומדוברת

מחקר על מידת האפקטיביות של הוראה משולבת של ערבית ספרותית ומדוברת לתלמידי תואר ראשון במחלקה ללימודי המזרח התיכון והאסלאם באוניברסיטת חיפה.

**יוזם המחקר:** עמי פדהצור. המחקר מתוכנן להתנהל עם חוקרים נוספים; הרכב הצוות וחלוקת האחריות טרם תועדו.

**מצב הפרויקט:** הקמת תשתית ותכנון לקראת תוכנית הוראה חדשה שטרם החלה. הושלמה סקירת ספרות קצרה ראשונית. אין עדיין בריפו פרוטוקול מאושר, נתונים או ממצאי המחקר המקומי.  
**תאריך פתיחת התיעוד:** 2026-09-14.  
**תחילת הוראה מתוכננת:** אוקטובר 2026; יום מדויק טרם נמסר.  
**מחזור ראשון צפוי:** 15–20 סטודנטים; זהו אומדן היקף הלומדים, ולא מספר משתתפי מחקר שגויסו.  
**מאגר התיעוד:** https://github.com/pedahzur/Arabic

## תיעוד כל צעד

בסיום כל יחידת עבודה מהותית מעדכנים את התוצר הרלוונטי ואת יומן המחקר, עם תאריך, מבצע, הפעולה, תוצאה, מגבלות וקישורים. החלטה מתודולוגית נרשמת גם ביומן ההחלטות. עבודה שלא הושלמה מסומנת במפורש.

הדיון יכול להתנהל ב־[Issues](https://github.com/pedahzur/Arabic/issues), אך מסמכי הריפו הם התיעוד המצטבר. תבנית למשימת מחקר זמינה בעת פתיחת Issue. בשלב ההקמה טרם נפתחו משימות או הוקצו חוקרים.

הריפו ציבורי. נתוני סטודנטים, טופסי הסכמה, הקלטות ותמלולים ברמת משתתף יישמרו באחסון מוגבל גישה שייקבע על ידי הצוות. פרטי המדיניות נמצאים ב־[data/README.md](data/README.md).
