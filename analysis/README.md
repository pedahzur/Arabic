# תכנון ניתוח ושחזור

**מצב:** אין כאן עדיין נתונים, קוד ניתוח או תוצאות. רכיבי הניתוח ייקבעו אחרי בחירת המערך והתוצא הראשי.

לפני ניתוח יש לתעד את האומד או ההשוואה המבוקשים, יחידת הניתוח, מדידות חוזרות, תלות בתוך כיתות ומורים, משתני בסיס, טיפול בחסרים ובנשירה, וריבוי בדיקות ככל שרלוונטי.

לכל הרצה בעתיד יתועדו:

- גרסת הקוד והסביבה, פקודת ההרצה וזרע אקראי אם נעשה שימוש באקראיות.
- מזהה גרסת נתונים ואופן הגישה המורשה, בלי לחשוף מידע חסוי.
- בדיקות איכות, חריגות ותוצרי ההרצה.
- הבחנה בין ניתוח שתוכנן מראש לניתוח שנוסף לאחר עיון בנתונים.

תוצרים המועלים לריפו הציבורי ייבדקו גם לזיהוי עקיף של משתתפים. אין להוסיף פלטי מחברות שמכילים רשומות נתונים או סודות. החלטה על רכיב איכותני ועל אופן שילובו תתועד בפרוטוקול.
