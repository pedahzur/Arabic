# כתיבה ותוצרים

**מצב:** טרם נכתבו דוח, מאמר או ממצאי מחקר.

לכל טיוטה יתועדו מטרתה, קהל היעד, שפה, מחברים או תורמים כפי שסוכמו, גרסה ותאריך. טענות אמפיריות יקושרו למקור או לתוצר ניתוח; יש להפריד בינן לבין פרשנות והצעות פדגוגיות.

הציטוטים יהיו לפי Chicago 17, Notes–Bibliography, עם כתובות מאומתות. בחירת כתב עת, כללי מחברות והחלטות על הפצה יתועדו כאשר יתקבלו.
