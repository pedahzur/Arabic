# פגישות צוות

**מצב:** טרם תועדו פגישות.

לכל פגישה יוצרים קובץ בשם YYYY-MM-DD-short-topic.md לפי ../templates/meeting.md. מתעדים משתתפים בפועל, חומרים שנבדקו, החלטות ומשימות עם אחריות ומועד אם הוסכמו.

החלטות נרשמות גם ביומן ההחלטות. אין לפרסם כאן פרטי סטודנטים, הערכות אישיות חסויות או תמליל מלא של דיון ללא בחינת התאמתו לריפו הציבורי.
