# כלי מדידה וחומרי הוראה

**מצב:** לא נבחרו או נבנו כלים. לא נשמרו כאן תשובות משתתפים.

לכל כלי יש לפתוח מסמך עם מזהה INS, מטרת המדידה, גרסה ותאריך, שפה וניב, אוכלוסיית יעד, מקור וזכויות שימוש, הוראות, מחוון ותהליך בדיקת התאמה. אם מדובר בכלי קיים, יש לתעד מה שונה מן המקור.

שומרים כאן רק כלים ריקים וחומרי הוראה שניתן לפרסם. חומרי בחינה חסויים, תשובות, הקלטות ומחברות סטודנטים יישמרו באחסון המוגבל. שינויים בכלי לאחר תחילת איסוף מחייבים תיעוד של הגרסה שהועברה לכל מחזור.
